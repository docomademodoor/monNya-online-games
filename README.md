# MonNya Online Games

ブラウザ上で遊べるオンライン対戦ゲームです。

## 概要

- Node.js + Express + Socket.IO を使ったリアルタイム対戦
- 大富豪とチンチロを収録
- 2人以上でルームを作成して対戦可能
- チンチロは最大8人、CPU参加にも対応
- ルール選択により、ローカルルールを調整可能
- スマホ・PC向けのレイアウト
- Render 上で簡単に公開可能

## 必要環境

- Node.js 20 以上
- npm

## ローカル開発

```bash
npm install
npm run dev
```

ブラウザで以下を開いて遊べます。

```text
http://localhost:3000
```

## 本番起動

```bash
npm install
npm start
```

## 本番デプロイ

このリポジトリには Render 用の設定ファイルが含まれています。

- `render.yaml`

Render で新規 Web Service を作成し、GitHub リポジトリを接続すると自動デプロイされます。

### デプロイ手順

1. GitHub にこのリポジトリを push
2. Render にログイン
3. New + Web Service を選択
4. GitHub リポジトリを接続
5. `render.yaml` を検出して設定を適用
6. Deploy を実行

## 構成

- `src/core/roomState.js`: ルーム状態、プレイヤー形状、再接続、参加申請など、ゲームに依存しないルーム基盤
- `src/core/gameRegistry.js`: ゲーム種別と最大人数を解決する共通Registry
- `src/game/gameRegistry.js`: 現在利用できるゲーム定義の登録場所
- `src/game/roomManager.js`: 共通ルーム運営とゲームengineへの委譲
- `src/game/daifugo/`: 大富豪の定義、ラウンド開始、カード判定、特殊効果、CPU
- `src/game/chinchiro/`: チンチロの定義、ラウンド進行、役判定
- `src/server.js`: Socket.IOイベント、通知、タイマーの接続

ゲームの識別子、表示名、最大人数は各ゲームの `definition.js` に置き、`src/game/gameRegistry.js` で登録します。ルーム共通処理は `src/game/roomManager.js`、ゲーム固有の初期化や状態公開は各フォルダーの `engine.js` が担当します。

## チンチロ

- 3個のサイコロを使い、1ターン最大3回まで振れます。3回目で自動確定し、それより前に役を確定することもできます。
- 強さはピンゾロ、シゴロ、ゾロ目、ペア、役なし、ヒフミの順です。ゾロ目とペアは目で比較します。
- 役なし同士は出目の昇順で比較し、同じ強さは同順位になります。
- 順位に応じて「参加人数 - 順位 + 1」点が加算され、次のラウンドへ累計します。

- 8切り
- 革命
- マーク縛り
- スペ3返し
- 階段
- 階段革命
- Jバック
- 数字縛り
- 5飛び
- 7渡し
- 10捨て
- ♢3スタート
- 都落ち
- 禁止上がり
- ジョーカー込み

## ルール説明

- 8切り: 8を含む出し方で場を流す
- 革命: 4枚以上を同時に出すと、カードの強さが反転する
- マーク縛り: 同じマークのカードだけが続けて出せるようになる
- スペ3返し: ♠3を使ってJOKERの場を返し、次の場を作り直す
- 階段: 同じマークの連番を出せる
- 階段革命: 同じマークの連番4枚以上で革命を起こす
- Jバック: Jを含む出し方で、場が流れるまで強さが逆転する
- 数字縛り: スートを問わず、同じ枚数の同ランク出しが1つずつ続いたら、次のランクだけ出せる
- 5飛び: 5を含む出し方で飛ばし、人数超過時は自分の番に戻る
- 7渡し: 7を出すと次の人へ枚数分を受け渡す
- 10捨て: 10を出すと、手札から1枚を捨てる
- ♢3スタート: ♢3を持つ人からスタートする
- 都落ち: 前回の大富豪が失敗した場合、都落ちの判定が入る
- 禁止上がり: 最後の1枚で上がるのは禁止
- ジョーカー込み: ジョーカーを含めてゲームを進行する
